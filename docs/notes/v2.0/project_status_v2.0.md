## 结果与局限

研究范围为局部晚期或转移性 PDAC 系统治疗。主候选要求同癌症 NGS 报告严格早于候选日。腺癌 NOS、特殊或混合组织学、派生转移日期和治疗意图分别保留证据与不确定性标记。

第五阶段将 35 条组织学归属疑点及 7 条疾病情境疑点移入待核查组，登记记录总量保持 4,411 条。候选日、NGS 日期和原始证据保持来源定义。候选分组尚不等同于独立临床决策、最终训练资格或专家标签。

## 后续工作

为开发集中25名Pilot建立病例与候选方案的标签审核对。按候选日组织病理、分子检测、既往治疗及疾病状态，关联冻结目录中的适用条件、原始证据与四类标签判定依据。实际后续用药和结局单独呈现，不能进入决策前病例输入。

当前目录以已核验的公开原始资料为边界；最新版CSCO/NCCN完整推荐表的未核验范围及其影响见[证据边界](treatment_evidence_ledger_v2.0.md)。病例初标、专家审核及模型评价尚未开展。
