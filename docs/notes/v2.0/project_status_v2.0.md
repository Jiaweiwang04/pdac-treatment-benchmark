## 已确认结果与解释范围

第一阶段保留1,109名患者、3,532份病理及7,627个标本，核对58,947条临床记录。第二阶段生成58,019个时间轴事件，从3,153条方案记录登记3,404个候选锚点，其中251个是方案内其他药物的开始日期。

主要分子数据整理包括1,130个样本、7,911条小变异、236条结构变异及离散CNA和面板信息。连续拷贝数区段尚未解析，临床变异解释及药物证据未开展。

以上都不是最终可用决策点数量。用户本轮确认仅推进Track A、冻结Track B；ECOG、常规肝肾功能和毒性等临床指标不作为本轮筛选门槛。病理、NGS报告日期、癌症归属及当前治疗情境仍需核查。第三阶段已按NGS严格在先的要求重建分层，并补充进展候选待核查组；最新数值见[Track A报告](track_a_candidate_report_v2.0.md)。

## 下一阶段与待明确事项

研究重点已确认：局部晚期／转移性PDAC系统治疗；以指定截止日的知识重评为主，历史实际方案仍需同期与当前指南、论文支持。文献截止日暂定2026-09-10，尚未冻结。

用户已确认NGS报告必须严格早于决策，同日先后未知保留待核查。最新集合由第三阶段重新生成，方案起始主候选、方案内调整及进展触发候选分开统计。下一步核查派生转移日期与手术病理同日、当前局部晚期情境、非典型及冲突组织学，以及方案起始／后加药／进展归组是否构成独立治疗决策。结局单独保留供案例参考，不进入事前输入和标签判断；候选点核查后再进入治疗方案证据、标签和pilot审核。
