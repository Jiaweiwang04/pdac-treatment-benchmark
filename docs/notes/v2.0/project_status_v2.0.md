## 结果与局限

研究范围为局部晚期或转移性 PDAC 系统治疗。主候选要求同癌症 NGS 报告严格早于候选日。腺癌 NOS、特殊或混合组织学、派生转移日期和治疗意图分别保留证据与不确定性标记。

第五阶段将 35 条组织学归属疑点及 7 条疾病情境疑点移入待核查组，登记记录总量保持 4,411 条。候选日、NGS 日期和原始证据保持来源定义。候选分组尚不等同于独立临床决策、最终训练资格或专家标签。

## 后续工作

两名专家分别审核病例时点与候选方案的匹配标签，再对主标签、研究属性、适用路径和关键条件的分歧进行裁定。依据审核结果修订标签说明，并统计逐类修改原因与一致性。预拟标签不进入专家金标准字段。

本轮采用代表性方案选择，不能用175项的标签比例估计总体分布。临床信息可用时间、历史用药具体历年与同期依据、未裁定的ROS1候选路径及公开指南读取边界，见[Pilot审核协议](pilot_review_protocol_v2.0.md)。
