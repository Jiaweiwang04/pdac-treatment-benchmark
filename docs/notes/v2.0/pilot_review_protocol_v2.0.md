# Pilot 治疗方案标签审核协议 v2.0

版本：v2.0

更新日期：20260915

状态：175条预拟标签已形成；两名专家独立审核及分歧裁定尚未完成。

## 范围与审核单位

使用已锁定的25名开发集Pilot患者，每名患者采用一个已锁定的索引候选点。审核单位是“病例时点×候选治疗方案”，不是对决策点本身或实际疗效作判断。每例6至8项，共175项；两名专家分别填写，共350个独立审核位置。

本轮是有目的的代表性选择，覆盖常规、分子相关、研究性及边界路径，并保留候选日实际药物记录。不是全部64个方案家族的穷举，也不是可代表总体标签比例的随机样本。既往实际治疗和后续结局不决定标签。四类标签的完整定义见[标签说明](treatment_label_definition_v2.0.md)。

## 病例与时间处理

病例摘要保留诊断年龄、性别、原发部位、初诊分期、登记组织学和候选日疾病情境。病理按照每次取材及每个标本展开，包括阴性标本、原位与浸润性记录、癌症类型和原组织学。共66份候选日前取材的报告、132个标本。报告签发时间未确认的状态不因摘要而消失。

25份NGS均为同癌症、报告严格早于候选日；关联218条小变异、结构变异、离散拷贝数及面板信息。无小变异记录不能解释为阴性；突变数量不能替代TMB；原始变异注释不能自动解释为致病胚系改变。病理原表中嵌入的晚到MMR结果不随早期取材记录进入候选输入。

既往疗程仅计同癌症、候选日前已开始的组分；结束日期若晚于或等于候选日，输入中保持未确认。其他癌症治疗另存。病例PILOT-09与PILOT-25后续增加的药物，仅在全程参考中展示；不得据完整疗程倒推候选日的计划。候选日之后的影像、就诊、治疗、生存及全程登记字段独立保存。

`pilot_decision_inputs_v2.0.jsonl`是按时间与字段白名单组织的审核资料；其中取材或就诊日期在先但可用时间未确认的事实仍带时间限制。`pilot_case_source_records_v2.0.jsonl`保留全程追溯材料，不能作为模型输入文件直接读取。

## 方案与证据

候选选择见[选择配置](../../../code/config/v2.0/pilot_review_selection.json)。本轮涉及23个冻结家族、28条来源；另有4条实际药物记录因匿名或完整组成证据未定位而保留身份缺口。27项标为研究性方案，研究属性与四类主标签分别记录。

依据冻结目录的知识截止日2026-09-12评价。预拟标签为支持匹配12项、条件性匹配101项、有依据不匹配22项、无法判定40项；此分布不代表专家共识。每项保留使用情境、判定理由、未知或冲突条件、证据编号及病例来源引用。

相同药物组成不保证相同剂量日程，OFF与mFOLFOX6等情境保留冲突。已发表阴性或不足以支持的研究不因存在人体结果而取得正向标签。实际方案的历史研究与当前证据分开；病例具体历年及同期可得性未确认的记录，不声称已完成同期合理性验证。

目录和患者划分锁保持不变。PILOT-12的SLC4A4–ROS1融合及原报告“功能意义未定”说明完整保留，其治疗路径尚未裁定；不借用NTRK路径，也不扩展冻结目录。

## 独立审核与裁定

首轮显示预拟标签。两名专家分别使用独立审核表副本，填写专家编号、日期和每条最终选择；修改时说明适用路径、病例事实或证据上的理由。双方提交前不交换结果。显示预拟标签可能造成锚定影响，在实验报告中说明。

两份独立结果均保留，逐项比较主标签、研究属性及关键条件。存在分歧的项目进入裁定表；裁定人填写最终标签、理由、未解决问题及日期。未完成的专家字段和裁定字段保持空白，不以预拟标签填补，不形成金标准。

## 局限与后续

临床资料的时间、治疗意图及部分组织学仍不完整；其影响落实在具体标签条件中。最新版CSCO和NCCN完整推荐表尚未逐项核验，候选目录具有明确来源边界。资料保真、时间截断及编号一致性检查不能替代临床判断。

完成双人独立审核后，统计逐类分歧、修改原因和一致性，并分析预拟标签的锚定影响。依据裁定形成Pilot参考标签，再决定标注规则是否需要修订。不得以本轮代表方案分布估计全队列性能或据Core实际治疗反向补建目录。
