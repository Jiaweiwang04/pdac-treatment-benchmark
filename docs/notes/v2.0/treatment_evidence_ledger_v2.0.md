## 证据冲突与版本边界

OFF和mFOLFOX6保持独立变体及相反结果方向；不能挑选阳性研究代表整个家族。试验注册、扩大使用许可、正式批准与临床结果不是同一类证据，须按事件日期及文件类型记录。

证据清单与药名规范化是待审核研究资料，未形成专家裁定标签。目录定义、参考项处理和内容摘要已冻结，专家审核状态独立记录。结构化来源见[证据表](../../../data/processed/v2.0/07_treatment_catalog/treatment_evidence_sources_v2.0.csv)。
