标签以指定截止日期的指南和论文知识重评为主。患者实际采用的历史方案保留在候选池，后续分别补充同期证据和当前证据。观察到使用不等于有效、最优或当前适用，未使用也不等于负例。临床指南和论文检索尚未开展，不填写虚构引用。

输入为第一阶段逐字段保真的十张临床表及PANC原始分子文件、变量字典。运行前重新核对临床原值，并核对72个源文件校验和。原数据只读，中间数据存入data/processed/v2.0/02_decision_points，统计和病例网页存入code/results/v2.0/02_decision_points。

## 候选锚点定义

每条方案记录登记一个整套方案开始锚点，另登记该方案内不同药物开始日。相同日期的药物归入同一锚点。后加药可能只是多日给药安排、计划中的联合用药或实际方案调整，当前只登记候选，不能自动当作独立决策或换线。

药物结束日不直接生成停药、减药或支持治疗决策；数据缺少相应意图与原因。试验药名称被遮蔽时，保留遮蔽状态，开始与结束同日不解释为真实单日疗程。停止后重新开始的同药方案不自动删除；数据指南规定超过一定治疗间隔可登记为新方案。

全部目标与非目标癌症记录保留。每个候选可回到患者、癌症序号、方案记录及源文件逻辑行。候选锚点数量不是可用训练决策点数量。

## 时间与信息可用性

统一以患者第一个目标癌症诊断日为第0天。癌症、方案和放疗按所属癌症诊断偏移；病理取材、影像、内科评估和标志物采用原表相对首个目标癌症的日期。NGS采用报告日期，并与另一条独立日期换算结果比较。

PD-L1、MSI和MMR逐次展开最多三组，ER/PR/HER2最多五组，分别使用其报告或附加报告日期。整份报告中的“任何一次阳性”不能替代逐次检测的时点结果。

| 分类 | 条件 | 用途 |
| --- | --- | --- |
| confirmed_before | 明确报告日期早于锚点 | 可进一步核查癌症归属和检测语义 |
| event_before_availability_unconfirmed | 事件在先，主报告可用日期未知 | 作为待核查资料，不能宣称已知 |
| same_day_order_unknown | 同日，无更细时间 | 保留先后未知 |
| future | 事件或报告在锚点之后 | 仅用于全程追溯 |
| unknown_time | 日期不足 | 不自动填0或纳入时点输入 |

每个患者的每个事件在每个候选下必须恰好进入一个分类。分类索引指向完整追溯记录，不是可直接输入模型的特征表；原诊断登记、全程方案成分、治疗结束、结局及随访字段可能含后续信息，仍需逐字段筛选。

## 情境与组织学分层

诊断时Stage IV或明确远处转移用于标记诊断时转移背景。诊断后的派生转移日期只有早于锚点时才支持“后续转移候选”；同日保留先后未知。派生转移日期仍需回查原证据，尤其是与手术病理同日的情况。

初次治疗前“不可切除／局部晚期或转移性”为合并字段，不能单凭它确定当前局部晚期，也不能无条件沿用到后续方案。本阶段保留局部晚期候选，待核查是否发生切除、进展或治疗情境改变。

全程NGS OncoTree码只用于回顾性队列亚型索引，不作为早期时点特征。PAAD不自动等同于已经确诊PDAC。病理仅在原文明确写为8500 Ductal adenocarcinoma、癌种为Pancreatic Cancer且浸润为Yes时标记直接组织学支持；腺癌NOS、其他8500表述或混合组织学均保留原文，不自行改写。取材日在先的直接支持仍不解决报告何时可用。

## 信息充分性与验证

本轮只推进Track A，Track B冻结。ECOG、常规肝肾功能、剂量、完整毒性等Track B临床指标不作为本轮候选纳入或质量分层门槛；原始数据说明可记录缺失，但不据此排除Track A病例。Track A评价分子证据、病理与疾病情境、既往治疗及候选方案匹配，不宣称完成个体临床安全性或剂量可行性评价。病理、时间顺序和癌症归属的缺口仍需明确处理。

测试覆盖报告迟于取材、同日先后未知、跨癌症日期、未知病理日期、未来转移、后加药及遮蔽结束日。还检查候选与事件编号唯一、时间分类不重不漏、分子样本与患者关联及临床原值一致。

所有候选的最终训练／测试资格为not_finalized，治疗适用性标签为空。正式纳入需要进一步核查临床情境和组织学，并明确缺失资料下是否采用条件性标签。

## 本轮候选边界约定（20260910）

以下为用户本轮确认的v2.0范围。第二阶段保留全量治疗锚点；第三阶段执行Track A分层并补充进展候选归组。新结果见[Track A报告](track_a_candidate_report_v2.0.md)。方案内调整和进展候选组不自动视为独立决策；手工语义核查尚未完成。

1. 仅推进Track A，冻结Track B。旧方案中的Track A概念可查[归档研究方案第3.2节](../../../warehouse/archive/v1.0/original_project/docs/notes/research_plan_pdac_treatment_benchmark_v3.0.docx)，旧版筛选结果、规模和标签不继承为v2.0结论。
2. 候选识别围绕治疗策略变化：开始治疗、换方案、维持治疗及既往方案再次使用。分日给药与单纯延迟不给出独立决策身份；加药或撤药需有策略改变的证据，不能解释的记录保留待核查。仅凭药物结束日不推断停止治疗或撤药原因。
3. 信息不足先保留分层，不立即删除。分层依据是Track A所需病理、分期和当前情境、分子报告与时间、既往治疗及事件可解释性；腺癌NOS不自动改写为PDAC，所有病理原始字段仍完整保留。
4. 有明确进展证据和可定位时间、但未记录后续治疗的事件纳入候选池。进展记录不等于已经确认的独立决策；同一次进展的多条记录需要聚合核查，不能把每次复查都当成新决策。没有后续治疗记录不等于选择停止治疗或支持治疗。
5. 保留用药后的反应、进展和结局作为全程案例参考，区分后续治疗未记录、随访不足和已有结局。没有记录不补造结局或停药原因，不因缺少完整结局自动删除候选。结局不直接生成候选治疗的正负标签。
6. 决策当时已知的信息和决策之后的结局分开存储、展示。对既往治疗的反应若在当前决策前已知，可作为既往史；当前待评治疗之后的反应只进入后续参考。未来病例信息不进入模型输入，也不用于专家事前候选标签判断。

用户已确认沿用NGS报告必须早于决策的要求。正式规则为报告日严格小于t0，并核实报告日期换算一致及癌症直接关联；同日但先后未知不进入主候选。迟到、未知或归属不清的NGS保留待核查，不把未来检测倒用于早期节点。进展候选暂以最早进展事件日作保守时间锚点，真实报告可用日与决策日另行核查，不能为了满足NGS在先而改用较晚重复进展日期。

第三阶段执行前的历史基线（不代表最新候选集合）：主要范围2,441个候选点、871名患者，其中1,238个候选点、565名患者具有当前关联规则下明确早于决策的NGS报告，另1,203个候选点尚无此类确认。1,238个包含1,150个方案起始锚点和88个方案内药物开始锚点；不是独立决策或最终纳入数，也尚未加入进展但未记录后续治疗的新增候选。不同子集的患者可能重叠，患者数不能直接相加或相减。
