# 候选决策点处理协议 v2.0

版本：v2.0

更新日期：20260912

状态：五阶段筛选规则已实现；临床裁定和治疗标签待完成。

## 研究范围与标签口径

研究对象为局部晚期或转移性 PDAC 的系统治疗。围手术期治疗、其他癌症和非 PAAD 亚型记录分别标记，保留为背景或范围外资料。

候选方案评价采用知识截止日期内的指南和论文，并分别保存历史实际方案的同期与当前证据。观察到使用不等于有效或适用，未使用也不构成负标签。文献截止日固定为 2026-09-12（用户已确认），检索尚未完成，见 [配置](../../../code/config/v2.0/decision_points.json)。四类主标签与研究性方案标记见[标签定义](treatment_label_definition_v2.0.md)。知识更新与患者信息时间分别处理。

## 输入与来源

输入包括十张临床表的保真记录、PANC 分子文件和变量字典。运行前核对临床原值及 72 个源文件校验和。数据指南第 24、89、130、140、164、173、176—177 页及变量字典支持关联键、方案边界和日期解释，详见 [数据用途说明](source_usage_report_v2.0.md)。

## 候选锚点定义

每条方案记录形成一个方案开始锚点，方案内不同药物开始日另行登记，同日药物归为一个锚点。后加药可能对应分日给药、计划联合治疗或策略调整，仅凭开始记录不能确认换线。药物结束日缺少停药意图和原因，不能直接生成停药或支持治疗决策。试验药遮蔽值保持原义。

进展候选来自明确记载 `Progressing/Worsening/Enlarging` 且存在癌症证据的影像或内科评估。存在更晚治疗开始记录的进展保留为历史证据；其余连续进展按观察过程归组。稳定、改善或 Mixed 后再次进展开新组，未知评估不切组，同日相反评估标记冲突。归组采用最早事件日，不随后续 NGS 到达而后移。进展组尚不代表已知的实际决策日。

## 时间与信息可用性

统一时间原点为患者第一个目标癌症诊断日。癌症、治疗和放疗日期按所属癌症偏移；病理取材、影像、内科评估和标志物按原表定义换算。NGS 使用报告日期，并核对独立日期换算及直接癌症关联；主候选要求报告日严格小于 `t0`。

PD-L1、MSI 和 MMR 最多三组，ER/PR/HER2 最多五组，各次检测使用独立报告或附加报告日期。报告中的综合阳性标志不能替代逐次检测结果。

| 时间分类 | 定义 |
| --- | --- |
| `confirmed_before` | 明确报告日在锚点之前 |
| `event_before_availability_unconfirmed` | 事件在先，报告可用时间未知 |
| `same_day_order_unknown` | 同日，先后未知 |
| `future` | 事件或报告在锚点之后 |
| `unknown_time` | 日期不足 |

每个候选下的患者事件恰好属于一个时间类别。完整事件层用于追溯，诊断汇总、全程方案成分、治疗结束、结局和随访等字段还需经过特征选择。后续结局另存为参考数据；已在当前决策前获知的既往治疗反应可用于病史，当前治疗之后的反应不进入该治疗的事前输入。

## 情境与组织学分层

诊断时 Stage IV 或明确远处转移支持诊断时转移背景；诊断后的派生转移日期需严格早于锚点并保留来源核查。初始不可切除性不能直接代表后续局部晚期状态，尤其需核查切除及治疗情境变化。

回顾性 OncoTree 亚型用于队列索引，同癌症决策前 NGS 编码用于候选证据，两者分别存储。直接导管腺癌支持要求标本原文为 `8500 Ductal adenocarcinoma`、癌种为 `Pancreatic Cancer` 且浸润为 `Yes`。腺癌 NOS 与在先 PAAD 可保留候选资格，但亚型及病理主报告时间仍标为未确认。

同药或后一方案为前一方案药物子集、且意图不明的记录列入独立性待核查；药物集合比较使用全程资料，仅用于记录核查。同日进展与同患者、同癌症的治疗开始关联，保留双向索引及未知先后，不另计独立点。

第五阶段按 [候选集合配置](../../../code/config/v2.0/candidate_cohort.json) 将逐点组织学冲突和疾病情境疑点单列，主候选、进展扩展及治疗调整附录分别保存。组织学关键词是核查信号，不自动构成非 PDAC 诊断；同患者其他候选按各自证据独立判断。

## 信息充分性与验证

筛选使用分子、病理、疾病情境、既往治疗及其时间信息。公开数据缺少稳定的 ECOG、常规肝肾功能、完整剂量和毒性记录，这些字段不设为候选筛选门槛，也不据此评价个体临床安全性或剂量可行性。缺失值保持未知。

测试覆盖跨癌症关联、报告晚于取材、同日先后、未知日期、未来转移、后加药、遮蔽药物、进展归组、同日关联及逐点组织学筛查。候选编号和事件编号唯一，时间分组不重不漏，临床原值与源文件逐字段一致。

## 输出与复现

执行 `python -B code/scripts/run_v2_0.py all` 重建五阶段。候选表及来源明细分别位于 `data/processed/v2.0/02_decision_points/` 至 `05_candidate_cohort/`；统计和运行清单位于对应的 `code/results/v2.0/` 子目录。方法、阶段数量与局限见 [文档索引](project_document_index_v2.0.md)。
